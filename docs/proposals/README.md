# Proposals

Feature proposals, research spikes, and technical explorations for Odyssey.

Each document in this folder is a self-contained write-up covering a potential feature or technical direction — including motivation, technical approach, integration points, trade-offs, and next steps.

## Status Labels

Proposals use a status in their frontmatter:

| Status | Meaning |
|--------|---------|
| **draft** | Early exploration, still being researched |
| **ready** | Fully written up, ready for a decision |
| **accepted** | Approved for implementation |
| **in-progress** | Actively being built |
| **shipped** | Landed in the app |
| **shelved** | Not pursuing right now, but preserved for later |

## Naming Convention

Files are named `NNN-short-title.md` (e.g., `001-on-device-llm.md`). Numbers are assigned sequentially and never reused.
